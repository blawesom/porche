cause (verified upstream): Outscale's IMDS is EC2-style

support 2026-11-09. FCOS 44 (our pin) AND current stable
45.20261030.3.1 (meta.json pkgdiff verified: ignition 2.27.0,
afterburn 5.11.0) predate it — no FCOS build today can consume
Outscale user-data or keypair injection. The MS-5.M2 "Ignition-via-
UserData proven" note was evidently never proven ON Outscale; doc 13
§4.12's workaround targets cloud-init images (Rocky), not Ignition.
KeypairName would not help either (Afterburn lacks the provider).
